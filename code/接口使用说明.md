# 科目3 无人机路径规划 - 接口说明

## 📂 项目结构

```
code/
├── config/                          # 配置文件目录（输入接口）
│   ├── obstacles.csv               # 障碍物配置表格
│   ├── start_points.csv            # 起点配置表格
│   └── goal_points_initial.csv     # 终点配置表格
│
├── run_example/                     # 运行脚本
│   ├── run_with_config.py          # 主运行脚本（读取配置）
│   ├── evaluate_metrics.py         # 独立评估脚本（计算指标）
│   ├── config_loader.py            # 配置加载模块
│   └── mamp/                       # 规划器核心代码
│
└── output/                          # 输出目录
    ├── trajectory_output.json      # 轨迹和结果输出
    └── metrics.json                # 性能指标输出
```

## 🔧 接口设计

### 输入接口

#### 1. 障碍物配置 (`config/obstacles.csv`)

| 列名 | 说明 | 示例 |
|------|------|------|
| 编号 | 障碍物编号 (1-19) | 1 |
| 类型 | 1=圆柱, 2=立方体, 3=U型, 4=旋转立方体 | 1 |
| 中心x | X坐标 (北方向, 米) | 300 |
| 中心z | Z坐标 (东方向, 米) | -267 |
| 尺寸1 | 圆柱半径/立方体长度 (米) | 60 |
| 尺寸2 | 立方体宽度 (米) | 0 |
| 高度 | 高度 (米) | 50 |
| 运动信息 | "静态" 或 "运动" | 静态 |

**说明**：
- 类型4（旋转立方体）的障碍物10、11、12为动态障碍物
- 运动参数（振幅、周期、方向）由于题目未给出，代码中保持原有设定

#### 2. 起点配置 (`config/start_points.csv`)

| 列名 | 说明 | 示例 |
|------|------|------|
| 无人机编号 | UAV编号 (1-24) | 1 |
| X(m) | X坐标 (北方向, 米) | 0 |
| Y(高度) | Y坐标 (高度, 米) | 0 |
| Z(侧向) | Z坐标 (东方向, 米) | -40 |

#### 3. 终点配置 (`config/goal_points_initial.csv`)

格式与起点配置相同。

## 🚀 使用流程

### 步骤1：准备配置文件

将比赛提供的障碍物表格、起点表格、终点表格放入 `config/` 目录：

```bash
cd code
ls config/
# obstacles.csv  start_points.csv  goal_points_initial.csv
```

### 步骤2：运行规划器

```bash
cd run_example

# 基础运行（使用默认配置）
python run_with_config.py --config-dir ../config --mode competition

# 保存输出到指定文件
python run_with_config.py \
  --config-dir ../config \
  --mode competition \
  --cycles 2000 \
  --output output/trajectory_output.json

# 指定随机种子
python run_with_config.py --config-dir ../config --seed 42
```

**运行模式说明**：
- `fixed` - 固定目标点（无干扰）
- `switch` - 3500m目标切换
- `sin` - 正弦扰动目标  
- `random` - 随机噪声目标
- `competition` - 综合模式（切换+正弦+随机，复赛标准）

### 步骤3：计算性能指标

```bash
# 从轨迹输出计算指标
python evaluate_metrics.py --input output/trajectory_output.json

# 保存指标到文件
python evaluate_metrics.py \
  --input output/trajectory_output.json \
  --output output/metrics.json
```

### 步骤4：查看结果

```bash
# 查看指标文件
cat output/metrics.json

# 或使用评估脚本的格式化输出
python evaluate_metrics.py --input output/trajectory_output.json
```

## 📊 评估指标说明

根据比赛要求，计算以下指标：

### 基础指标
- **成功**: 是否完成规划
- **任务完成时间**: 从起点到所有UAV到达的时间（秒）
- **到达UAV数量**: 成功到达终点的UAV数量（/24）

### 安全距离指标
- **最小UAV间距**: UAV之间的最小距离（要求≥3.0米）
- **最小静态障碍物间距**: UAV与静态障碍物的最小间距（要求≥1.5米）
- **最小动态障碍物间距**: UAV与动态障碍物的最小间距（要求≥1.5米）

### 碰撞统计
- **UAV碰撞次数**: UAV间距小于3.0米的次数
- **静态障碍物碰撞次数**: 与静态障碍物间距小于1.5米的次数
- **动态障碍物碰撞次数**: 与动态障碍物间距小于1.5米的次数

### 规划性能指标
- **目标更新次数**: 动态目标更新的次数
- **全局引导重规划次数**: A*全局路径重新规划的次数
- **动态排斥次数**: 动态障碍物导致的轨迹调整次数
- **K3求解次数**: 三次多项式求解次数
- **K5求解次数**: 五次多项式激活次数
- **联合搜索次数**: 多UAV协调搜索次数
- **回退次数**: 规划失败回退次数

## ⚠️ 注意事项

1. **动态障碍物运动参数**：由于题目表格未给出振幅、周期、方向，代码中保持原有设定
2. **坐标系**：代码使用 `[x, y, z] = [North, Up, East]`，与题目 `[X, Y(高度), Z(侧向)]` 一致
3. **Y坐标计算**：障碍物中心Y坐标 = height/2（题目表格未明确给出）
4. **配置文件编码**：请使用UTF-8编码保存CSV文件
