```python
# config_loader.py
def load_obstacles_from_csv(csv_path):
    obstacles = []
    with open(csv_path, 'r') as f:
        reader = csv.DictReader(f)
        for row in reader:
            obstacle = (
                int(row['编号']),
                int(row['类型']),
                float(row['中心x']),
                float(row['中心z']),
                float(row['尺寸1']),
                float(row['尺寸2']),
                float(row['高度'])
            )
            obstacles.append(obstacle)
    return tuple(obstacles)  # 返回与原代码相同格式

# subject3_environment.py
def load_obstacles_from_config(csv_path=None):
    global SUBJECT3_OBSTACLE_TABLE
    SUBJECT3_OBSTACLE_TABLE = load_obstacles_from_csv(csv_path)
```

**引用关系**：CSV表格 → 元组 → 覆盖全局变量 ✅

**修改后**：
```python
def build_subject3_changed_goals(csv_path=None):
    """Return the 24 replanned terminal points from table 3.
    
    Args:
        csv_path: Optional path to goal_points_changed.csv
    """
    if csv_path and Path(csv_path).exists():
        from config_loader import load_points_from_csv
        return load_points_from_csv(csv_path)  # 从CSV加载
    
    # 原有默认值（保持兼容）
    unchanged = build_subject3_initial_goals()[:8]
    side_group = np.column_stack((np.full(8, 5000.0), np.full(8, 20.0),
                                  np.arange(-575.0, -539.0, 5.0)))
    rear_group = np.column_stack((np.full(8, 4800.0), np.full(8, 10.0),
                                  np.arange(540.0, 576.0, 5.0)))
    return np.vstack((unchanged, side_group, rear_group))
```

**使用位置**：`GoalManager` 在目标切换时会使用 `environment.changed_goals`
- 当运行模式为 `switch` 或 `competition` 时
- UAV距离原点3500m触发切换
- 自动切换到 `changed_goals` 中的对应位置
